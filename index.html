คำแนะนำการใช้งาน

  1. เลือกประเภทข้อมูลที่ต้องการตรวจสอบ ได้แก่ NET หรือ COM
  2. วางข้อมูล JSON ที่คัดลอกจากระบบ CNS หรือเลือกไฟล์ JSON
  3. กดปุ่ม “แปลงข้อมูล” เพื่อแสดงรายการในรูปแบบตาราง
  4. ใช้ช่องค้นหาและตัวกรองเพื่อค้นหารหัสโรงเรียน ชื่อโรงเรียน อำเภอ และสถานะการบันทึก
  5. กดปุ่ม “ดำเนินการ” เพื่อเปิดหน้ารายการของโรงเรียนนั้นในระบบ CNS

ข้อมูล JSON จะถูกประมวลผลภายใน Browser เท่านั้น ระบบนี้ไม่จัดเก็บหรือแก้ไขข้อมูลในระบบต้นทาง
